# Checklist sebelum repository dipublikasikan

- [ ] Source code dan dokumentasi dapat dibaca serta dijalankan.
- [ ] README berisi instalasi, cara menjalankan, pengujian, dan batasan.
- [ ] `requirements.txt` sudah sesuai dengan import yang digunakan.
- [ ] `.env` tidak masuk commit; hanya `.env.example` yang boleh dibagikan.
- [ ] Tidak ada API key, token, password, atau secret pada kode dan riwayat Git.
- [ ] Tidak ada NIM, nomor identitas, alamat, email pribadi, atau data sensitif pada file publik.
- [ ] Screenshot tidak menampilkan informasi akun atau API key.
- [ ] Lisensi file/dokumen pada `knowledge_base/` sudah diperiksa.
- [ ] Artikel berhak cipta tidak diunggah tanpa izin.
- [ ] Unit test dijalankan dan hasilnya dicatat.
- [ ] Evaluasi retrieval dijalankan dan hasilnya disimpan bila sudah diperoleh.
- [ ] Repository Public sudah diperiksa dari browser tanpa login.
- [ ] URL repository sudah dibuka ulang untuk memastikan link benar.
