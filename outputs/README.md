# Outputs

Folder ini menampung file hasil evaluasi yang dihasilkan ketika skrip dijalankan.

Jalankan:

```bash
python scripts/run_retrieval_evaluation.py
```

Skrip akan membuat `retrieval_evaluation.csv` dan `retrieval_evaluation.json`. File hasil belum disertakan sebagai bukti karena perlu dihasilkan pada lingkungan yang digunakan untuk menjalankan repository ini.
