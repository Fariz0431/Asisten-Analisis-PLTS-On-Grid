# Knowledge base

Folder ini berisi delapan dokumen awal untuk baseline retrieval, sesuai jumlah awal yang dihitung dalam rancangan proyek (`5 + (K mod 4) = 8` untuk K=31). Delapan file ini terdiri atas enam catatan ringkas artikel dan dua catatan dokumentasi teknis PVsyst.

**Penting:**
- D1–D6 merupakan catatan kerja berdasar informasi bibliografi dan peran relevansi yang dicantumkan dalam rancangan proyek. Catatan tidak menggantikan artikel asli dan tidak memiliki kutipan halaman.
- D7–D8 merupakan ringkasan dokumentasi resmi PVsyst dengan URL sumber.
- Retrieval yang menemukan sebuah chunk tidak membuktikan bahwa chunk tersebut menjawab pertanyaan.
- Jangan tambahkan PDF artikel berhak cipta ke repository publik tanpa memastikan lisensi/izin. Prioritaskan catatan buatan sendiri dan tautan DOI.
- File PDF yang tidak memiliki lapisan teks dapat terbaca kosong; OCR tidak dijalankan oleh aplikasi.
